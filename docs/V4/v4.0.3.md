# AkademikOS Release Specification — V4.0.3

**Versi:** `v4.0.3`

**Status:** `Telah Diimplementasikan & Aktif di http://localhost:3001`  

---

## Ringkasan Perubahan V4.0.3

Penyempurnaan pada rilis V4.0.3 difokuskan pada peningkatan estetika antarmuka bersih (Anti-Slop & Material Design 3), struktur dokumen otentik, tata letak yang stabil, dan kenyamanan penulisan catatan kuliah.

---

### 1. RPS & Materi: Pembersihan Ukuran File, Kode Kriptik & Pratinjau Dokumen Otentik
- **Penghapusan Label Ukuran File (`MB`):**
  - Seluruh label ukuran berkas (`4.2 MB`, `2.8 MB`, dll.) telah dihapus dari daftar file dan folder tree untuk menjaga tampilan tetap bersih dan minimalis.
- **Penghapusan Kode Mata Kuliah Kriptik:**
  - Kode-kode acak seperti `IF-3104` telah dihapus. Nama berkas dan silabus kini langsung menampilkan nama mata kuliah yang jelas dan manusiawi (*contoh: "RPS - Kecerdasan Buatan (Sem Gasal 2026/2027)"*).
- **Pratinjau Lembar Akademik Otentik (Paper-Style Preview):**
  - Pratinjau dokumen di sisi kanan (60%) dirombak menjadi lembar silabus/RPS akademik resmi berstandar universitas:
    - **Kop Resmi:** Departemen Ilmu Komputer dan Elektronika, Fakultas MIPA, Universitas Gadjah Mada.
    - **Tabel Capaian Pembelajaran Lulusan (CPL) & Mata Kuliah (CPMK).**
    - **Rencana Perkuliahan Semester:** Rincian pekan ke-1 s.d. pekan ke-14 beserta bahan kajian.
    - **Komposisi Evaluasi & Penilaian:** Tugas, Kuis, Proyek Akhir, dan Ujian.
    - **Daftar Pustaka Utama:** Referensi literatur standar internasional (Russell & Norvig, Mitchell, Goodfellow).

---

### 2. Catatan Kuliah: Folder Hierarki ala Obsidian & Editor Layar Penuh
- **Folder Tree Collapsible (Sisi Kiri ~30%):**
  - Folder mata kuliah dapat dibuka dan ditutup (*collapsible*) dengan ikon folder dinamis (`Folder` / `FolderOpen`).
  - Mendukung penambahan folder baru (`+ Folder Baru`) dan pembuatan catatan langsung di dalam folder.
  - Setiap berkas catatan memiliki ekstensi eksplisit (`.md` atau `.txt`) dengan tanggal modifikasi.
- **Text & Markdown Editor Interaktif (Sisi Kanan ~70%):**
  - **Judul Berkas Interaktif:** Judul catatan dapat diubah secara langsung dan sinkron dengan daftar berkas.
  - **Toolbar Markdown Cepat:** Tombol format instan untuk Heading (`H1`, `H2`), Bold, Italic, Bullet List, Task Checklist, dan Code Block.
  - **Tombol Layar Penuh (Fullscreen Button):** Menekan tombol `Maximize2` akan memperluas editor ke mode *distraction-free fullscreen* tanpa sidebar dan header, dengan tombol keluar layar penuh (`Minimize2`).
  - **Statistik Kata & Karakter:** Menghitung jumlah kata dan karakter secara langsung tanpa memberatkan kinerja.

---

### 3. Perbaikan Tata Letak Sidebar (Sticky Layout Fix)
- **Masalah Sebelumnya:** Ketika konten halaman utama (dasbor, kalender, atau materi) memanjang ke bawah, bilah sisi kiri (*sidebar*) ikut terdorong atau terseret ke bawah sehingga menyisakan ruang kosong yang canggung di bagian atas.
- **Solusi Implementasi V4.0.3:**
  - Wrapper sidebar diubah menjadi:
    ```tsx
    sticky top-2.5 sm:top-3.5 h-[calc(100vh-1.25rem)] sm:h-[calc(100vh-1.75rem)] z-30
    ```
  - Komponen sidebar memiliki tinggi `h-full` dengan scroll internal yang mandiri (`overflow-y-auto`).
  - Hasil: Sidebar tetap terkunci rapi di tempatnya pada layar monitor, sementara area konten utama dapat di-scroll bebas.

---

### 4. Pembersihan Deskripsi Kecil & Subtitle Redundan (Anti-Slop Strict)
- Seluruh teks petunjuk/basa-basi berlebih yang mengotori UI telah dibersihkan:
  - Dihapus: *"Tampilan kalender perkuliahan mahasiswa..."*
  - Dihapus: *"Klik kartu untuk melihat rincian atau mengubah jadwal"*
  - Dihapus: *"Tambahkan tugas baru secara instan..."*
  - Dihapus: Penjelasan-penjelasan kecil lainnya di tab Pengaturan, Radar, dan Quiz.
- **Informasi Fungsional Tetap Dijaga:**
  - Rentang waktu perkuliahan (`09.00 - 11.30 WIB`, `13.00 - 15.30 WIB`) tetap ditampilkan secara tegas dan akurat.

---

### 5. Perlindungan Konfigurasi Git & Database Lokal
- Berkas basis data SQLite lokal (`prototype/data/akademikos.db*`) telah dimasukkan ke dalam `.gitignore` dengan pola:
  ```gitignore
  data/*.db*
  ```
- **Kepatuhan Perintah:** Tidak ada perintah `git commit` maupun `git push` yang dijalankan oleh sistem asisten. Semua perubahan siap dan diserahkan kepada pengguna untuk dilakukan peninjauan, penambahan (*stage*), dan commit mandiri.
